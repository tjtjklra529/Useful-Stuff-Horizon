# Original Horizon quiver artwork

Created from scratch using the built-in image-generation tool for the November 22, 2026 Horizon review correction. No reference image or Minecraft bitmap was supplied. The old Mojang-derived quiver was removed from the corrected Horizon assets. Java editions were not changed.

`source-generated.png` is the generated source; `quiver-16.png` is the actual game texture. Conversion uses nearest-neighbor sampling to 16×16, binary alpha, and a 16-color palette. `quiver-preview.png` is a 20× nearest-neighbor enlargement, not an in-game screenshot.

Prompt: Create one original inventory-item sprite, not based on Minecraft's unused quiver or any existing asset. Transparent 16×16 logical pixel grid, flat 2D, no labels or shadows outside sprite. Slightly tilted dark teal waxed-canvas arrow case, warm tan diagonal leather strap, small copper clasp, two light ash-wood arrows with cream feather fletching and rust-red accents. Restrained roughly twelve-color palette, stepped one-pixel contours, darker brown/teal edges rather than solid black. No pre-existing sprite as reference.
